## 게임에 대한 간단한 소개

**게임명:** Elemental Puzzle Drag

**게임 소개:**
하나의 드롭을 드래그해 퍼즐판을 재배치하고, 같은 속성 드롭을 3개 이상 연결해 연쇄 콤보와 공격을 발생시키는 실시간 퍼즐 전투 게임입니다. 퍼즐앤드래곤의 조작 방식과 전투 흐름을 참고했으며, 프로젝트에서는 드래그 퍼즐 조작, 연쇄 처리, 스킬 사용, 몬스터 전투 흐름을 구현했습니다.

## 목표 변경 내용

### 1. 퍼즐 조작 시간을 10초에서 20초로 변경

실제 조작해 보니 10초는 드롭을 충분히 움직이며 연쇄를 설계하기에 짧다고 판단했습니다. 조작 난이도를 완화하기 위해 최종적으로 조작 시간을 20초로 변경했습니다.

### 2. 내부 보드 구조를 표시 영역보다 크게 구성

화면에는 6×5 퍼즐판을 표시하지만, 연쇄 후 드롭 낙하와 재보충 처리를 위해 내부적으로는 추가 행을 포함한 구조를 사용했습니다.

## 아쉬운 것들

### 1. 레벨 밸런싱

후반부 난이도 상승은 의도했으나, 처음 플레이하는 사람에게는 다소 어렵게 느껴질 수 있습니다. 실제 서비스용이라면 초반 난이도를 낮추고 후반 상승폭을 더 완만하게 조정할 필요가 있습니다.

### 2. 튜토리얼 부족

드롭을 단순히 한 칸씩 바꾸는 방식이 아니라 계속 끌고 다니는 방식이라 처음에는 설명이 필요합니다. 실제 출시를 고려한다면 조작법, 스킬, 속성 상성 설명을 추가해야 합니다.

### 3. 확장 요소

현재는 기본 공격과 기본 매칭 중심으로 구성했습니다. 더 발전시킨다면 몬스터별 특수 행동, 5개 이상 연결이나 특정 모양 연결에 따른 추가 효과를 넣을 수 있습니다.

## 수업에 대한 내용

### 기대한 것

스마트폰 게임 개발에서 PC 게임과 다른 부분, 특히 터치 입력, 화면 비율 대응, 모바일 환경의 리소스 관리, Android 프로젝트 구성을 배울 것으로 기대했습니다.

### 얻은 것

터치 기반 조작, Android 환경의 2D 게임 루프, Scene과 World 기반 구조, 객체 재활용, 사운드 처리, 리소스 관리 등을 익힐 수 있었습니다. 특히 a2dg 구조는 이번 프로젝트의 기반으로 직접 활용할 수 있었고, 레이어 분리와 객체 재활용 방식은 다른 게임 개발에도 응용 가능하다고 느꼈습니다.

### 얻지 못한 것

수업이 2D 게임 제작 중심이라 3D 모바일 게임 개발에 필요한 렌더링, 카메라, 조명, 3D 모델 처리, 모바일 3D 최적화 등은 깊게 다루지 못한 점이 아쉬웠습니다. 2D 모바일 게임의 기본 구조를 배우는 데는 도움이 되었지만, 3D 게임으로 확장하려면 별도 학습이 필요하다고 느꼈습니다.
